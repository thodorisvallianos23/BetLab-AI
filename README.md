# ⚽ BetLab AI

BetLab AI is a football analytics project focused on identifying value betting opportunities using statistics instead of intuition.

## Version

v1.0

## Features (Roadmap)

- Goal Prediction Model
- Expected Goals (xG)
- Poisson Goal Simulation
- Over/Under Probabilities
- BTTS Prediction
- Team Rating
- Value Finder
- Dashboard
- Reports

## Future Modules

- Team Shots
- Corners
- Cards
- Fouls
- Player Props

## Tech Stack

- Python
- Pandas
- NumPy
- SQLite
- Streamlit
